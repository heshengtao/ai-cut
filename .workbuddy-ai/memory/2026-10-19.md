- 新建 `ai-cut` 项目：Tauri 2 + Vue 3 + TypeScript + Vite + Tailwind 3 + Pinia，UI 沿用 `ai-daw` 的 MD3 设计令牌与组件风格。
- 移除原生标题栏：`src-tauri/src/lib.rs` 里 `WebviewWindowBuilder::from_config` + macOS `TitleBarStyle::Overlay` / `hidden_title(true)`，Windows/Linux `decorations(false)`；`tauri.conf.json` 窗口 `create: false`。

- 右侧边栏：标签页模式（媒体库 / 属性 / AI 助手 / 导出），支持关闭、`+` 选择器、标签溢出自动滚到可视区。

- 开发端口固定 **1430**（1420 被 ai-daw 占用），`tauri.conf.json` 的 `devUrl` 同步。

## pnpm 启动修复

- 用户用 `pnpm tauri dev` 启动失败：pnpm 11 生成的 `pnpm-workspace.yaml` 里 `allowBuilds.esbuild` 是占位串 `set this to true or false`，导致 `[ERR_PNPM_IGNORED_BUILDS]` 并让 pnpm 在运行脚本前自动执行的 `pnpm install` 失败。
- 修复：改为 `allowBuilds:\n  esbuild: true`（pnpm 11 的正确写法，值为布尔）。
- 注意：该环境里 agent 无法跑 `pnpm install`（沙箱 brokered fs 在 node_modules 建符号链接会 `CODEBUDDY_BROKER_DENY`），验证改用已装好的 node_modules + `pnpm --config.verify-deps-before-run=none tauri dev`，窗口正常渲染。
- 项目内同时存在 `package-lock.json` 与 `pnpm-lock.yaml`，实际以 pnpm 为准。
