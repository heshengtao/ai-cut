# 域：人审与导出（review）

「AI 剪，人审片。」审片不是最后看一眼，而是分阶段的 Gate。每个 Gate 只回答一个问题；没通过不要往下走。

## 1. 审片 Gate

| Gate | 时机 | 只看什么 | 通过标准 |
| --- | --- | --- | --- |
| G0 | brief 后 | 目标、受众、平台、时长、画幅 | 一句话能说清；约束可验收 |
| G1 | 选型后 | 路线、成本、风险 | 预算内能做出目标画面 |
| G2 | 分镜后 | 故事、节奏、信息 | 每个镜头可执行、可验收 |
| G3 | 素材后 | 画面质量、一致性、缺口 | 有足够可用镜头；缺口有兜底 |
| G4 | 粗剪后 | 故事是否成立 | 无声也能看懂 |
| G5 | 精剪后 | 节奏、包装、品牌 | picture lock |
| G6 | 字幕/配音后 | 准确、同步、自然 | 无错字、无错位、无机械感 |
| G7 | 增强后 | 技术质量 | 无黑帧/爆音/糊脸/水印 |
| G8 | 终审 | 整体是否愿意署名 | 明确签收 |
| G9 | 导出后 | 文件是否可交付 | 规格/时长/响度/字幕通过 |

## 2. 通用审片顺序

1. **静音看**：故事、字幕、构图。
2. **闭眼听**：旁白、音乐、SFX、爆音。
3. **正常看**：情绪、节奏、品牌。
4. **手机上竖屏看**：字幕大小、安全区、静音自动播放。
5. **抽帧看**：首帧、转场、尾帧、字幕最大长度。

## 3. 终审清单

### 故事

- [ ] 3 秒内知道在讲什么？
- [ ] 每一段只推进一个信息？
- [ ] 有明确的起承转合/问题-方案-证据-CTA？
- [ ] 结尾有行动指令？
- [ ] 没有自嗨的内部术语？

### 画面

- [ ] 构图干净，主体明确
- [ ] 镜头运动有理由，不抖不晕
- [ ] 色彩/曝光统一
- [ ] 生成镜头没有变形、闪烁、多余手指
- [ ] 品牌元素（logo、字体、色板）正确
- [ ] 没有水印/试用版标记

### 字幕

- [ ] 无错字、错译、专有名词错误
- [ ] 断句自然，一行不超过 16–18 中文字符
- [ ] 不遮挡主体/平台 UI
- [ ] 与语音同步（误差 < 0.2s）
- [ ] 数字、价格、日期、单位准确
- [ ] 双语字幕不重叠

### 声音

- [ ] 旁白清楚，不被音乐盖住
- [ ] 音乐不循环到烦，段落有起伏
- [ ] SFX 不抢戏、不刺耳
- [ ] 无爆音、无削波、无突然静音
- [ ] 响度符合平台（通常 -14 LUFS，真峰值 ≤ -1 dBTP）
- [ ] 左右声道平衡

### 合规

- [ ] 所有素材有来源与许可证
- [ ] 真人肖像/声音有授权
- [ ] 音乐/字体可商用
- [ ] 生成内容符合平台政策
- [ ] 没有未授权的竞品/商标
- [ ] 医疗/金融/法律陈述有依据

### 平台

- [ ] 画幅/时长/文件大小符合平台
- [ ] 首帧不是黑帧
- [ ] 自动播放（静音）也能看懂
- [ ] 结尾留出平台 UI 空间

## 4. 反馈格式

每条意见必须可执行：

```md
[时间码] 优先级 类别：现象 → 期望 → 建议动作
```

示例：

```md
[00:03.2] P0 声音：旁白被音乐盖住 → 旁白应清楚 → 音乐降 6 dB 或做 ducking
[00:12.8] P1 画面：B-roll 是旧版 UI → 换成当前版本 → 重新录屏 12–15s
[00:21.0] P1 字幕：第二行超出安全区 → 一行放下 → 缩到 16 字以内并重新断句
[00:34.5] P2 节奏：停顿 1.5s 太长 → 更紧凑 → 切掉 0.8s
[00:41.0] P0 合规：音乐来源不明 → 必须有商用授权 → 换曲或购买授权
```

优先级：

- **P0**：阻断交付（错误信息、爆音、黑帧、版权、平台违规）。
- **P1**：必须修（影响理解、品牌、观看体验）。
- **P2**：有余力再修（审美微调）。

**不要接受「感觉不对」这种反馈。** 追问：哪个时间点、哪个元素、期望是什么。

## 5. 意见处理

1. 把意见写进 `review-<date>.md`，不要只留在聊天里。
2. 按 P0 → P1 → P2 排序；P0 未清零不导出。
3. 每条意见对应一条或多条命令；同一条意见的修改可以用 `apply_commands` 合成一个撤销步。
4. 修完只回读受影响的片段（`get_track` / `get_clip`）验证；关键帧、调色、蒙版、转场用 `render_frame` 或 `render_storyboard` 导出 PNG 自检，再请人复核。
5. 如果意见冲突（A 要快、B 要慢），回到 brief 的成功标准裁决。

**不要把不同意见混进同一批**：审片后的修改要能按意见回退。

## 6. 导出规格

| 平台 | 画幅 | 分辨率 | 帧率 | 时长 | 备注 |
| --- | --- | --- | --- | --- | --- |
| YouTube 长视频 | 16:9 | 1920×1080 / 3840×2160 | 24/25/30/60 | 无硬限 | 首帧有信息；字幕可选 |
| YouTube Shorts | 9:16 | 1080×1920 | 30/60 | ≤ 60s（推荐 15–45s） | 底部留 UI 安全区 |
| TikTok / Reels | 9:16 | 1080×1920 | 30 | 15–90s | 前 1.5s 抓人；字幕大 |
| Instagram Feed | 1:1 / 4:5 | 1080×1080 / 1080×1350 | 30 | ≤ 60s | 封面可另出 |
| X / Twitter | 16:9 / 1:1 | 1280×720 / 720×720 | 30 | ≤ 2:20 | 文件大小限制 |
| 微信视频号 | 9:16 / 16:9 | 1080×1920 / 1920×1080 | 30 | 短 | 字幕安全区 |
| B 站 | 16:9 | 1920×1080 | 30/60 | 长 | 封面/标题另做 |
| 客户母版 | 按需 | 4K / ProRes | 按需 | 按需 | 保留无字幕版 |

**AI Cut 导出选项**

- MP4：H.264/AAC，质量 high/standard/small = CRF 18/23/28。
- ProRes：`.mov`，ProRes 422，PCM 48k；适合母版/后期。
- GIF：任意尺寸（建议用自定义小尺寸控制体积）、默认 15fps、可配颜色数/抖动/循环、无音频；只适合短循环。
- 自定义尺寸：`resolution: "custom"` + `width` / `height`；`fit: "cover"` 裁切（`fitAnchor` 选保留区域），`contain` 加边。
- 文字片段会烧录；当前不导出独立 SRT/VTT。

## 7. 导出后校验

```bash
# 容器与流信息
ffprobe -v error \
  -show_entries format=duration,size,bit_rate,format_name \
  -show_entries stream=index,codec_type,codec_name,width,height,r_frame_rate,sample_rate,channels \
  -of default=noprint_wrappers=1 output.mp4

# 黑帧检测（前 3 秒与全片）
ffmpeg -i output.mp4 -vf "blackdetect=d=0.1:pix_th=0.10" -an -f null - 2>&1 | grep blackdetect

# 音频峰值（需要 astats）
ffmpeg -i output.mp4 -af "astats=metadata=1:reset=1" -f null - 2>&1 | grep -E "Peak level|RMS level"
```

检查：

- [ ] 时长与预期误差 < 0.1s
- [ ] 分辨率/帧率正确
- [ ] 视频编码 H.264（或 ProRes），像素格式 `yuv420p`（MP4）
- [ ] 音频 48 kHz、双声道、AAC 192k（MP4）
- [ ] 首帧/尾帧不是黑帧
- [ ] 字幕没有被裁切
- [ ] 文件大小适合平台
- [ ] 文件名符合交付约定

## 8. 版权与合规清单

- [ ] 每个素材有来源 URL/凭证
- [ ] 许可证允许商用、修改、分发
- [ ] 需要署名的已署名
- [ ] 真人出镜有肖像使用同意
- [ ] 声音克隆有声音权利人同意
- [ ] 音乐/字体/模板有授权
- [ ] 生成模型条款允许当前用途
- [ ] 没有未授权的商标/品牌元素
- [ ] 敏感信息（人脸、车牌、地址、工牌、聊天记录）已处理

## 9. 交付包

```
<project>/
  output/
    <name>_<platform>_<resolution>.mp4
    <name>_master.mov          # 可选
    <name>_cover.png           # 可选
  project.aicut.json
  brief.md
  script.md
  storyboard.csv
  manifest.json
  review-<date>.md
  LICENSES.md
```

`LICENSES.md` 汇总所有第三方素材/字体/音乐/模型的许可证与署名要求。**没有它，交付不算完成。**

## 10. 签收模板

```md
# 审片签收

- 项目：<name>
- 版本：v<final>
- 审片时间：<date>
- 结论：通过 / 有条件通过 / 退回

## 未关闭项
- [ ] P0 …
- [ ] P1 …

## 备注
<需要后续处理但不阻断交付的事项>
```

**只有人明确写下「通过」或「可以导出」，才进入导出。** 智能体不要替人签收。
