# 第二批注入点 + 私有插件落地（M4）实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 补上 spec 里承诺的第二批注入点（`ai.pane`、`board.inspector`），并用一个「H3 风格」示例插件证明：multipart 提交 → 轮询 → 直链下载 → 产物入库 这条链路完全能在插件里跑通，主仓库不出现任何私有 API 细节。

**Architecture:** 两个注入点都是「一张 Map + register/disposer + 一个渲染分支」；H3 风格插件复用 M2 的宿主半能力，端到端测试用本机 HTTP 服务模拟那三个接口。

**Tech Stack:** Vue 3（`component :is` 动态组件）、Rust（M2 的 `ctx.http`）。

**设计依据：** [`../specs/2026-11-17-plugin-architecture-design.md`](../specs/2026-11-17-plugin-architecture-design.md) §10.2、§17
**前置：** M0–M3。

## Global Constraints

- 插件注册的 id 一律带插件前缀（`ctx` 已自动加），控件 / 页面 id 冲突报错并指出占用者。
- 动态组件只从注册表取，不许插件直接返回 HTML 字符串（避免 XSS 面）。
- 示例插件是**通用形态**：只演示协议形状，不包含任何真实服务的密钥 / 域名。
- i18n：新增文案同时进 `zh.ts` / `en.ts`。
- 每任务一次 commit。

### Task 1: 参数控件注册表（`board.inspector`）

- [ ] 类型：`BoardParamKind` 加 `"component"`；`BoardParamSpec` 加 `control?: string`（控件的注册 id）。
- [ ] `src/core/plugins/controls.ts`：

```ts
import type { Component } from "vue";

export interface ControlSpec {
  id: string;
  component: Component;
}

const CONTROLS = new Map<string, { spec: ControlSpec; owner: string }>();

export function registerControl(owner: string, spec: ControlSpec): () => void {
  if (CONTROLS.has(spec.id)) {
    throw new Error(`参数控件 ${spec.id} 已被 ${CONTROLS.get(spec.id)!.owner} 注册`);
  }
  CONTROLS.set(spec.id, { spec, owner });
  return () => {
    if (CONTROLS.get(spec.id)?.spec === spec) CONTROLS.delete(spec.id);
  };
}

export function controlFor(id: string): Component | null {
  return CONTROLS.get(id)?.spec.component ?? null;
}
```

- [ ] `ctx.controls.register(spec)` 接到 `PluginContext`（disposer 入栈）。
- [ ] `BoardNode.vue` 参数区在 `select` 之前插入分支：

```vue
<component
  :is="controlFor(spec.control ?? '') ?? 'input'"
  v-else-if="spec.kind === 'component'"
  :node="node"
  :spec="spec"
  :value="paramValue(spec)"
  @update="setParam(spec, $event)"
/>
```

### Task 3: H3 风格示例 + 端到端

- [ ] `examples/plugin-h3/`：
  - `client.js`：节点 `ext.h3.video`（参数：`base` 接口基址、`prompt`、`key`），adapter 调 `ctx.host.run(JSON.stringify({ base, key, prompt, image: io.asset("image")?.path }))`，宿主半返回产物路径 → `{ paths: [path] }`（自动入库）；
  - `host.js`：

```js
globalThis.__AICUT_PLUGIN__ = {
  id: "@aicut/plugin-h3",
  run(input) {
    const args = JSON.parse(input);
    const base = args.base.replace(/\/$/, "");
    // 1) multipart 提交
    const submit = JSON.parse(
      ctx.http.multipart(
        base + "/api/v1/tasks",
        JSON.stringify({ task_name: "minimax_h3_v2", prompt: args.prompt, resolution: "0.4", duration: "5" }),
        JSON.stringify(args.image ? { first_frame: args.image } : {}),
        JSON.stringify({ "X-Card-Key": args.key }),
        "POST",
      ),
    );
    if (submit.status !== 202 && submit.status !== 200) throw new Error("提交失败：" + submit.status);
    const taskId = JSON.parse(submit.text).data.task_id;
    // 2) 轮询
    for (let i = 0; i < 300; i += 1) {
      if (ctx.cancelled()) throw new Error("已取消");
      const poll = JSON.parse(
        ctx.http.request("GET", base + "/api/v1/tasks/" + taskId, JSON.stringify({ "X-Card-Key": args.key }), ""),
      );
      const status = JSON.parse(poll.text).data.status;
      if (status === "completed") break;
      if (status === "failed") throw new Error("任务失败：" + poll.text);
      const until = Date.now() + 1000;
      while (Date.now() < until) {}
    }
    // 3) 取直链 + 下载
    const fileUrl = JSON.parse(
      ctx.http.request("GET", base + "/api/v1/tasks/" + taskId + "/file-url", JSON.stringify({ "X-Card-Key": args.key }), ""),
    );
    const url = JSON.parse(fileUrl.text).data.url;
    return ctx.http.download(url, "", "h3.mp4");
  },
};
```

- [ ] `crates/daemon/tests/plugin_h3_demo.rs`：本机 HTTP 服务模拟 `/api/v1/tasks`（202 + task_id）、`/api/v1/tasks/{id}`（先 `processing` 再 `completed`）、`/file-url`、`/download`（返回 1 KB 假 mp4）；装插件（`kind=linked` 指向 `examples/plugin-h3`）→ `start` → `invoke` → 断言返回的路径是文件且非空 → `stop`。
- [ ] Commit：`feat(plugins): H3 风格示例插件与 multipart/轮询/下载端到端`

**执行期偏差与坑**

1. **宿主半运行态是进程级单例**：`plugin_host_state` 里 `start/stop` 同一个 id 会被其它并行测试干扰（`rejects_a_missing_base_url` 会把另一条用例正在跑的宿主半停掉）。两条场景合并成一个用例后稳定。
2. **手写 mock HTTP 服务不可靠**：连接复用 + 单方面关连接会让 reqwest 读到半截响应（"error decoding response body"）。改用 `axum`（加进 dev-dependencies）起本机服务，请求/响应语义交给真实的 HTTP 栈。
3. **`BoardParamKind` 新增 `component`**：参数区新增分支放在 `size` 之前，控件组件由 `controlFor(spec.control)` 解析；插件只能提供 Vue 组件，不能注入 HTML 字符串。
4. **`AiPane` 的 `aiPage` 从封闭联合放宽成 `string`**：`ext:<paneId>` 走插件页，内置页的 `v-if` 链不变。
